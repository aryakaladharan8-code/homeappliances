
# 🏠 Home Appliance Service Center

## 📌 Project Overview

The Home Appliance Service Center is a web-based platform developed using Django to connect customers with technicians for household appliance repair services. Users can submit service requests, find suitable technicians based on their location and ratings, and schedule appointments. The system also provides technician verification, service request management, invoice generation, and subscription management.

## 🎯 Problem Statement

Finding reliable technicians for household appliance repairs can be difficult. Customers may struggle to identify suitable technicians, coordinate service appointments, and track service requests. Technicians also need an organized platform to manage service requests and payments. This project aims to simplify the process by providing a centralized platform connecting customers, technicians, and administrators.

## 🎯 Objectives

* Simplify household appliance repair service booking.
* Connect customers with suitable technicians based on location and ratings.
* Improve communication between customers and technicians.
* Provide efficient service request and invoice management.
* Support technician verification and subscription management.

## ✨ Key Features

### 👤 User Features

* User registration and login.
* Submit household appliance repair requests.
* Find technicians based on location, ratings, and completed work.
* Specify preferred service dates and times.
* Receive email notifications about service request approvals or rejections.
* View service details and invoices.

### 🛠️ Technician Features

* Technician registration with identity verification documents.
* Admin approval before account activation.
* View and respond to service requests.
* Accept or reject requests based on availability.
* Enter service charges and generate invoices.
* Manage monthly subscriptions.
* Receive discounts based on ratings and completed service requests.

### 🔑 Admin Features

* Manage registered users and technicians.
* Verify technician identity documents and approve registrations.
* Monitor service requests and generated invoices.
* Manage technician subscriptions and eligibility for discounts.

### 📧 Notification System

* Email notifications for service requests and approval status.
* SMS notifications for service-related updates.

## 🔄 System Workflow

1. The customer submits a repair request with appliance details and a preferred service time.
2. The system displays suitable technicians based on the customer's location.
3. The customer selects a technician based on ratings and completed work.
4. The technician receives a notification and accepts or rejects the request based on availability.
5. The customer receives an email about the technician's decision.
6. After completing the repair, the technician enters the service charges and generates an invoice.
7. The administrator can monitor invoices and manage technician subscriptions.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Django
* **Database:** SQLite3
* **Notifications:** Email and SMS integration
